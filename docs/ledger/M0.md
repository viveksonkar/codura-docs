### M0-03 — DB foundation, tenancy base, embedding guard — **freezes specs/db.md §1–3**
- **Wave:** 2
- **Depends on:** M0-02, M0-04
- **Owns:** `backend/src/codura_docs/db/**`, `backend/migrations/**`, `alembic.ini`,

- **Spec:** [specs/db.md](../specs/db.md) §1–3

  - `platform_audit` table (append-only) for Platform Admin actions (FR-75)
  - Embedding guard: `api`/`worker` startup fails with an explicit message when configured

## Wave 3

### M0-06 — Postgres Job queue + worker loop
- **Wave:** 3
- **Depends on:** M0-03
- **Owns:** `backend/src/codura_docs/jobs/**`, `worker/**`
- **Implements:** ADR-0006; FR-04
- **Spec:** specs/db.md §3; ADR-0006
- **Acceptance criteria:**
  - `enqueue(session, kind, payload, run_after=None)` usable inside a caller's transaction;
    `tenant_id` taken from the session's `TenantContext`, never from the payload
  - Handlers run inside `tenant_session(job.tenant_id)`; claiming uses the `codura_worker` role
  - Worker: claim with `SKIP LOCKED`, lease renewal, reaper for expired leases, retries with
    backoff (10 s, 60 s, 5 min), `NonRetryable` exception → `failed` immediately, `LISTEN/NOTIFY`
    wake-up with polling fallback, graceful SIGTERM (finish or release current Job)
  - Handler registry keyed by `kind`; `noop` handler for the exit check
  - Tests: two workers never run the same Job; a killed worker's Job is reclaimed; retry counts
  - `POST /api/admin/debug/jobs/noop` (non-production only) enqueues a `noop`
- **Status:** [x] Done (2026-11-19)
