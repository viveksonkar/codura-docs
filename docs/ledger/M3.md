# Ledger — M3: Monetisation

**Status:** Workstream-level (decompose when M2 is near exit) · **Last updated:** 2026-11-19 · **Milestone ref:** [roadmap.md](../roadmap.md) M3 · **ADR:** 0019, 0021, 0022

**Exit criteria:**
- A Tenant upgrades from Trial to a paid Plan, via Stripe test-mode Checkout or a `manual` invoice.
- Overage at period end is invoiced exactly from the usage ledger (reconciliation test).
- The quota hard stop works on Free.
- The finance dashboard shows per-Tenant, per-Plan and per-Model margin and flags an unprofitable
  Tenant.
- The Plan editor refuses a below-floor price.
- A Tenant with the `custom_llm` Entitlement answers through its own endpoint, metered as
  `answer_custom_llm`.
- Premium Plans can use the Anthropic profile.

Spec to write in Wave 0: **`docs/specs/billing.md`**. It freezes the tables (`plans`,
`plan_versions`, `subscriptions`, `usage_counters` full form, `invoices`, `invoice_lines`,
`payments`, `cost_rates`), the Entitlement key registry and the PaymentProvider Port, all derived
from [billing.md](../billing.md). It is the freeze gate for everything below.
