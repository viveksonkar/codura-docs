# Ledger — M1: Tenants, Ingestion (incl. OCR), Retrieval, Answering, Admin

**Status:** Draft v0.3 · **Last updated:** 2026-11-19 · **Milestone ref:** [roadmap.md](../roadmap.md) M1

**Exit criteria:** MVP acceptance steps 1–6 and 8 ([requirements.md](../requirements.md) §6):
- Two organisations sign up and verify their email. Tenant Admin A invites a read-only Tenant User.
- A uploads a text PDF, a DOCX, a scanned PDF and a photo, and all reach `ready`.
- The Playground streams cited answers in two languages, cross-lingual included, and falls back on
  unrelated questions.
- Every answer and every ingested page writes a Usage Event with COGS.
- The Platform Admin's model override for A switches A's answers to an `openai_compat` profile with
  no code change.
- The Trial answer limit returns the limit-reached text.
- The isolation and role suites, the egress-blocked test and the eval report are green.
