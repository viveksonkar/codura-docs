# Ledger — M6: Production & observability

**Status:** Workstream-level · **Last updated:** 2026-11-19 · **Milestone ref:** [roadmap.md](../roadmap.md) M6 · **ADR:** 0013, 0022

**Exit criteria:**
- Deployed to production from CI-built images.
- Restore drill passes.
- Load test meets NFR-04/05 with several Tenants active.
- Grafana dashboards and alerts are live.
- LLM cost reconciliation runs monthly.
- Security review findings are closed or accepted.

| Workstream | Scope | Implements |
|---|---|---|
| Prod compose | `compose.prod.yml`: Caddy TLS, no internal ports, limits, restarts, log rotation, Docker secrets, `observability` profile on | NFR-03; SEC-12 |
| Image publishing | CI builds + signs images to GHCR on tag; SBOM | NFR-03; SEC-13 |
| Backup & restore | Backup/restore scripts, retention, CI restore drill, per-Tenant export | NFR-11 |
