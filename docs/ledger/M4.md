**Exit criteria:**
- The Channel parity checklist ([channels.md](../channels.md) §6) passes on the WordPress plugin
  (local WordPress via the `wp` profile) and the Android sample app (emulator).
- Both Channels are refused for Tenants whose Plan lacks them in the `channels` Entitlement.

**Toolchains (dev box, 2026-11-24):**
- **PHP 8.3** NTS is installed via winget, alongside WAMP's PHP 5.6. The machine PATH still lists
  5.6 first; use the 8.3 path, or move it ahead in the system PATH.
- **Android SDK** is at `C:\Android\sdk` (`ANDROID_HOME`): cmdline-tools, platform-tools,
  `platforms;android-35`, `build-tools;35.0.0`, JDK 17. An emulator system image is not installed yet
  (about 1.5 GB per ABI; the disk had about 20 GB free).

**Owner decision (Q5):** SDK + sample app is the default. A standalone app is out of scope until Q5

## Wave 1

### M4-01 — WordPress plugin core + settings
- **Wave:** 1 · **Depends on:** M4-00
- **Owns:** `wordpress/codura-docs-chat/**` (except `blocks/`)
- **Implements:** FR-42; SEC-14
- **Acceptance criteria:**
  - Settings page (`manage_options`, nonces, `sanitize_*`): API URL, `wordpress` Channel Key, mode,
    position, title, accent, language (auto/fixed), all pages + include/exclude rules
  - "Test connection" calls `/api/v1/channel/config` server-side and shows the Assistant name or the
    API error. It never leaks the key into page HTML beyond the element attribute
  - Front end enqueues the bundled `widget.js` (copied from `web/apps/widget/dist` at build) and
    prints `<codura-chat>` with `esc_attr`/`esc_url`. `uninstall.php` removes options
- **Status:** [ ] Not started

### M4-02 — WordPress tooling
- **Wave:** 1 · **Depends on:** M4-00
- **Owns:** `compose.wp.yml` / `wp` profile, `wordpress/phpcs.xml`, `wordpress/tests/**`, `.github/workflows/wordpress.yml`, `scripts/build-wp-zip.*`
- **Implements:** FR-42; ADR-0017
- **Acceptance criteria:**
  - `docker compose --profile wp up -d` → WordPress at `http://localhost:8081` with the plugin mounted
  - PHPCS (WordPress coding standards) and PHPUnit (WP test suite) green on PHP 8.1 and 8.3 in CI
  - CI builds `codura-docs-chat-<version>.zip`
- **Status:** [ ] Not started

### M4-03 — Android client `:codura-chat`
- **Wave:** 1 · **Depends on:** M4-00
- **Owns:** `android/settings.gradle.kts`, `android/codura-chat/**`, Gradle wrapper
- **Implements:** FR-43, FR-44, FR-53
- **Acceptance criteria:**
  - OkHttp SSE → `Flow<ChatEvent>` (meta/delta/citations/done/error), cancellation stops upstream
  - History, feedback, Visitor email + consent. DataStore keyed by Channel Key (conversation id,
    visitor id)
  - Unit tests replay `docs/specs/fixtures/sse/*` (MockWebServer). minSdk 24, JDK 17
- **Status:** [ ] Not started
