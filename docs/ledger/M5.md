# Ledger — M5: Quality & cost optimisation

**Status:** Workstream-level · **Last updated:** 2026-11-19 · **Milestone ref:** [roadmap.md](../roadmap.md) M5

**Exit criteria:**
- The eval gate blocks regressions in CI, overall and per language.
- Average COGS per answer drops measurably (answer cache + routing) with no eval regression.
- Reranker on/off is measured per Plan profile.

| Workstream | Scope | Implements |
|---|---|---|
| Answer cache | Per-Assistant cache of answers to near-duplicate questions (embedding similarity + same Knowledge Base version), invalidated on Document change; cache hits metered as `answer` at reduced COGS | billing.md §3; NFR-16 |
| Cost routing | Cheap profile for query rewrite / language tasks; prompt caching in Adapters that support it; per-Plan context budgets tuned from eval vs cost | ADR-0019, ADR-0021 |
| Reranker | Multilingual cross-encoder Adapter, per-Plan toggle, eval comparison | FR-15 |
| Better OCR (optional) | docling / vision-LLM `OcrEngine` Adapters for hard scans; per-Plan option | ADR-0016 |
| URL ingestion | URL + sitemap fetcher with SSRF protection (add SEC-21) | FR-09 |
| Eval gating | Thresholds per language and per profile in CI; eval runs per Plan profile | NFR-10 |
| Retention & settings | Per-Tenant Conversation purge, per-Tenant chunk settings | security.md §3 |
